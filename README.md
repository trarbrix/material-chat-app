# Material Chat

Основная версия Material Chat находится в файле `variant-b.html`: в нём собраны интерфейс, JavaScript и каталог эмодзи. Имя файла сохранено для совместимости с существующими приложениями и ссылками. Откройте `index.html` через статический веб-сервер, например `python3 -m http.server 8000`, затем перейдите на `http://localhost:8000/`. Можно также открыть `variant-b.html` напрямую. Прежний `manager.html` сохранён отдельно и не заменён.

Для входа и сообщений используется API: при открытии файла и на localhost — существующий `https://material-caht.onrender.com/api`, а на других хостах — `/api` того же сайта. Развёрнутого сервера API в этом репозитории нет; `server/` содержит только необязательное дополнение к отдельному серверу.

## Возможности

- Русский, английский, немецкий, украинский и французский языки; язык доступен также на экране входа.
- На телефоне список чатов, переписка и настройки открываются отдельными экранами; правила раскладки для ПК не заменяются.
- Вход и регистрация сохраняют интерфейс из предоставленного варианта `manager (1).html`. При ошибке отправки серверного кода клиент не придумывает код и не выполняет вход.
- Темы, анимации и параметры полей сохраняются в браузере. Энергосбережение отключает анимации, проверяет сообщения раз в 30 секунд; в обычном режиме — раз в 15 секунд. Опрос приостанавливается в скрытой вкладке, а при ошибках интервалы увеличиваются до двух минут.
- Профили с ником, необязательным юзернеймом и аватаром требуют установки серверного дополнения: см. `server/README.md`. В глобальном чате показываются публичные данные автора. До установки дополнения они не сохраняются на сервере.
- Дополнительные темы и настройки реакций перенесены из предоставленного варианта. Для обмена реакциями между пользователями сервер должен поддерживать `/api/reactions`; существующий старый сервер может не поддерживать этот маршрут. Дополнительные аккаунты требуют соответствующего серверного `/api/accounts` и авторизованной сессии.
- Настройка установки приложения показывает возможность установки только при поддержке браузера. Одного HTML-файла недостаточно для офлайн-PWA: для установки нужны дополнительные ресурсы и конфигурация сайта.
- Папки создаются кнопкой `+ / ⚙` над списком чатов или в настройках. Выберите чаты в папке; её можно переименовать или удалить без удаления чатов. Папки хранятся в localStorage отдельно для каждого имени пользователя на текущем устройстве.
- ИИ-помощник — отдельный локальный чат. В настройках чата укажите HTTPS-адрес OpenAI-совместимого `/chat/completions`, название модели и при необходимости ключ. Провайдер должен разрешать CORS-запросы из браузера; его использование может быть платным. Запросы и последние сообщения истории отправляются выбранному провайдеру. История хранится в localStorage по имени пользователя, ключ — только в памяти до перезагрузки страницы. Без настройки провайдера ответы не генерируются.
- При неудачной отправке сообщения интерфейс показывает HTTP-код или ошибку соединения и возвращает текст в поле ввода.
- Панель эмодзи в чате содержит категории и поиск по английским названиям, в том числе варианты оттенков кожи. Доступность конкретных символов зависит от устройства и шрифтов. Стикеры пока не реализованы.
- Параметры приватности скрывают имя и размывают сообщения **только на этом устройстве** (сообщения можно показать наведением или фокусом). Они не ограничивают доступ других пользователей и не обеспечивают шифрование. Настройки и папки не синхронизируются между устройствами.

Внимание: для настоящей приватности необходимы авторизация, проверка прав доступа и, при необходимости, шифрование на сервере. Их нельзя обеспечить настройками интерфейса; проверить или изменить сервер в этом репозитории невозможно.

## Проверки

`npm ci && npm test` запускает тесты интерфейса в jsdom с имитацией API. Это не проверка работы реального сервера или входа.

Данные эмодзи: unicode-emoji-json и emoji-datasource; лицензии находятся в `assets/`.

Также обратите внимание: новый серверный маршрут регистрации проверяет Telegram-код, но старый серверный `/api/auth` по-прежнему позволяет обходить эту проверку. До публичного запуска необходимо устранить существующие проблемы авторизации, перечисленные в `server/README.md`.

Обновление HTML само по себе не обновляет уже установленный APK: приложение необходимо пересобрать с новым HTML. При открытии HTML через `file://` запросы к серверу могут быть заблокированы Cloudflare/CORS; это изменение не устраняет эту серверную проблему.

## Основная версия

`variant-b.html` — основная версия приложения. Она включает отдельные мобильные экраны, прежние окна входа и регистрации, настройки языка, тем, папок, приватности и энергосбережения, эмодзи и отдельный настраиваемый чат с ИИ. Локальные папки и настройки не являются серверной защитой данных. Форма аватара сохраняется только в браузере.

Настройки разделены на пункты. В разделе «Темы и обои» можно выбрать узор, убрать фон или загрузить PNG, JPEG или WebP до 8 МБ; изображение уменьшается и хранится только в браузере на этом устройстве. Оно не отправляется на сервер и не видно собеседникам.

Вход и регистрация обращаются к серверу: при сбое клиент не создаёт тестовый аккаунт и не выдумывает код Telegram. Существующие данные локального демонстрационного режима из присланного файла не удаляются, но в рабочий серверный чат автоматически не переносятся. Профили требуют установленного серверного дополнения, а поиск пользователей, реакции, редактирование, пересылка и удаление сообщений — соответствующих серверных маршрутов; старый сервер может их не поддерживать. Переключение аккаунтов требует повторного входа. Установка PWA и офлайн-режим требуют дополнительной серверной конфигурации и файлов, не входящих в этот HTML.

Как и раньше, открытие через `file://` может приводить к Cloudflare/CORS-блокировке. Обновление HTML не изменяет установленный APK — его потребуется пересобрать. `npm test` проверяет интерфейсы с имитацией ответов API в jsdom, а не работу реального Telegram-бота или внешний вид на устройстве.

## Android APK

Предыдущая бета-сборка с фиолетовой иконкой: [`downloads/Material-Chat-beta.apk`](downloads/Material-Chat-beta.apk). Требуется Android 8 или новее и актуальный Android System WebView. Исходный Android-проект и инструкции сборки: [`android-app/README.md`](android-app/README.md). Это отдельное приложение; локальные настройки из браузера или другого APK автоматически не переносятся. Не удаляйте старое приложение без резервной копии данных. Последующие обновления этого APK должны быть подписаны тем же ключом.

Подпись и содержимое APK проверены инструментами сборки; на реальном Android-устройстве сборка ещё не проверялась. Работа входа и сообщений зависит от доступности сервера, его CORS и защиты Cloudflare; APK не устраняет серверные ограничения.

### Медиа и вход

Отдельная кнопка галереи открывает окно выбора: через системный выбор файлов добавьте до 20 фото или видео, просмотрите и удалите ненужные перед отправкой. Приложение видит только выбранные файлы: браузер не предоставляет автоматический доступ ко всей галерее устройства. Кнопка микрофона/камеры: короткое нажатие переключает голос и видеокружок без меню, удержание записывает, отпускание останавливает запись и открывает предварительный просмотр перед отправкой. Для управления с клавиатуры используйте Shift+Enter на кнопке записи: откроется окно с кнопками запуска и остановки. Если системный запрос разрешения прервал удержание, после разрешения запись не начинается автоматически: в открывшемся окне нажмите «Начать запись» или закройте его и удерживайте кнопку снова. В меню вложений остался выбор аудиофайла. Запись — до 60 секунд, каждый файл — до 20 МБ. Для записи нужны разрешения микрофона/камеры и поддержка `MediaRecorder`; файлы отправляются на существующий `/api/upload`, затем создаётся сообщение. Сервер может отклонить загрузку; на Render файлы без постоянного диска могут исчезнуть после перезапуска. На реальном телефоне и с живым сервером эти изменения ещё не проверены.

Экран входа получил фон и переходы; при выключенной анимации или системном reduced motion они отключаются. Редактор профиля больше не открывает отдельный запрос пароля; для сохранения по-прежнему необходима авторизованная сессия и установленный серверный модуль профилей. После истечения сессии нужно войти заново.

Старые APK и настольные релизы не обновляются автоматически из HTML. Для новых сборок нужны пересборка и проверка; обновление существующего APK требует прежнего ключа подписи, а не нового ключа.

### Прокрутка, фотографии и реакции

Основной экран занимает высоту окна. Список слева, история сообщений и панель настроек прокручиваются независимо, без прокрутки всей страницы. По нажатию на фотографию открывается просмотр с загрузкой и простым редактором (поворот и отражение). Изменённую копию можно скачать или отправить **новым сообщением**, исходник на сервере не заменяется. Для скачивания и редактирования сервер изображений должен разрешать CORS.

В клиенте исправлены отображение и обновление реакций. Для общих реакций необходимо установить и развернуть серверное дополнение `server/reaction_api.py` вместе с модулем профилей: см. `server/README.md`. Без серверного маршрута реакции не сохраняются и приложение показывает соответствующую ошибку. Старые сборки приложений из релиза не обновляются автоматически.

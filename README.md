# Material Chat

Весь интерфейс, JavaScript и каталог эмодзи находятся в одном файле `manager.html`: его можно целиком скопировать для проверки. Откройте `manager.html` через статический веб-сервер, например `python3 -m http.server 8000`, затем перейдите на `http://localhost:8000/manager.html`. Для входа и сообщений используется существующий внешний API, заданный в `manager.html`. Сервер API в этом репозитории отсутствует.

## Возможности

- Русский, английский, немецкий, украинский и французский языки; язык доступен также на экране входа.
- Темы, анимации и параметры полей сохраняются в браузере. Энергосбережение отключает анимации, проверяет сообщения раз в 30 секунд; в обычном режиме — раз в 15 секунд. Опрос приостанавливается в скрытой вкладке, а при ошибках интервалы увеличиваются до двух минут.
- Папки создаются кнопкой `+ / ⚙` над списком чатов или в настройках. Выберите чаты в папке; её можно переименовать или удалить без удаления чатов. Папки хранятся в localStorage отдельно для каждого имени пользователя на текущем устройстве.
- ИИ-помощник — отдельный локальный чат. В настройках чата укажите HTTPS-адрес OpenAI-совместимого `/chat/completions`, название модели и при необходимости ключ. Провайдер должен разрешать CORS-запросы из браузера; его использование может быть платным. Запросы и последние сообщения истории отправляются выбранному провайдеру. История хранится в localStorage по имени пользователя, ключ — только в памяти до перезагрузки страницы. Без настройки провайдера ответы не генерируются.
- При неудачной отправке сообщения интерфейс показывает HTTP-код или ошибку соединения и возвращает текст в поле ввода.
- Панель эмодзи в чате содержит категории и поиск по английским названиям, в том числе варианты оттенков кожи. Доступность конкретных символов зависит от устройства и шрифтов. Стикеры пока не реализованы.
- Параметры приватности скрывают имя и размывают сообщения **только на этом устройстве** (сообщения можно показать наведением или фокусом). Они не ограничивают доступ других пользователей и не обеспечивают шифрование. Настройки и папки не синхронизируются между устройствами.

Внимание: для настоящей приватности необходимы авторизация, проверка прав доступа и, при необходимости, шифрование на сервере. Их нельзя обеспечить настройками интерфейса; проверить или изменить сервер в этом репозитории невозможно.

## Проверки

`npm ci && npm test` запускает тесты интерфейса в jsdom с имитацией API. Это не проверка работы реального сервера или входа.

Данные эмодзи: unicode-emoji-json и emoji-datasource; лицензии находятся в `assets/`.

Также обратите внимание: существующая форма регистрации запрашивает код Telegram, но в запросе регистрации его не передаёт. До публичного запуска необходимо исправить и проверить серверный процесс подтверждения кода; один только клиент не доказывает, что аккаунт защищён.
